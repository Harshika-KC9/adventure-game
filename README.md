# adventure-game
A browser-based 2D adventure game built with HTML, CSS, and JavaScript featuring real-time player movement, enemy AI, combat mechanics, animations, and an interactive storytelling system.

* **Adventure Game** is an interactive, story-driven browser game where players take on the role of the main character and progress through an adventure by making decisions at different stages of the story.
* Unlike traditional games that rely on fast reflexes, combat, or continuous character movement, this game is driven entirely by **player choices**. Every decision shapes the storyline, making the player's judgment the key to success.
* Each choice leads to a different path, resulting in multiple possible storylines and endings. This branching narrative makes every playthrough unique and encourages players to explore alternative decisions.
* The objective is to navigate through various scenarios, solve challenges, and make thoughtful decisions that lead to a successful ending while avoiding choices that result in failure or unexpected consequences.
* The game is played entirely in the browser. Players read the scenario displayed on the screen, choose one of the available options, and watch the story unfold based on their decisions.
* Instead of following a fixed storyline, the game offers a dynamic experience where the narrative changes according to the player's actions, giving them control over how the adventure progresses.
* With multiple branches and endings, the game has high replay value, allowing players to replay it several times to discover hidden paths, different outcomes, and new story experiences.
* The project demonstrates core frontend web development concepts, including DOM manipulation, event handling, conditional logic, and dynamic content rendering.
